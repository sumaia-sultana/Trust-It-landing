# TrustIT 🌐

**TrustIT** is a modern, responsive IT services website designed to showcase technology solutions, company services, and client engagement features. It is built with a focus on clean UI, fast performance, and mobile-first design.

---

## 🚀 Live Demo
(https://trust-it-7a8bec.netlify.app/)

---

## 📌 Features

- Responsive landing page (mobile, tablet, desktop)
- Modern UI with Tailwind CSS
- Dark mode support (if enabled in your project)
- Service showcase section
- About section with company overview
- Contact form for client inquiries
- Smooth scrolling navigation
- Clean and maintainable code structure

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3 / Tailwind CSS**
- **JavaScript (Vanilla JS)**
- Optional: AOS / Framer Motion (if used)
