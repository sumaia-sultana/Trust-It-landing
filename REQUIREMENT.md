# 📘 Frontend Developer Assessment – Trust-IT (BD) Ltd

## 📌 Overview

Thank you for your interest in joining **Trust-IT (BD) Ltd**.

This assessment is designed to evaluate your **practical frontend development skills**, including your ability to build responsive interfaces, write clean code, and create user-friendly designs.

---

## 🎯 Objective

Build a **responsive and visually appealing landing page** for a fictional IT company.

Your implementation should demonstrate:

* Clean and modern UI design
* Proper semantic HTML structure
* Responsive layout across devices
* Strong CSS styling and layout skills
* JavaScript-based interactivity
* Well-organized and maintainable code

---

## 🛠 Required Technologies

### ✅ Mandatory

* HTML5
* CSS3
* JavaScript (Vanilla JS)

### ➕ Optional (Allowed)

* Tailwind CSS
* Bootstrap

---

## 📄 Required Sections

### 1. 🏠 Hero Section

Include:

* Company name or logo
* Main heading/title
* Short description/tagline
* Call-to-action (CTA) button

---

### 2. 🧩 Services Section

Display at least **three (3) services**.

Each service card must include:

* Icon or image
* Service title
* Short description

---

### 3. ℹ️ About Section

Include:

* Brief company introduction
* Image or illustration

---

### 4. 📬 Contact Form

Include the following fields:

* Name
* Email
* Message

#### Requirements:

* Implement **basic form validation using JavaScript**
* Display **clear validation error messages**

---

### 5. 🧭 Responsive Navigation Bar

Requirements:

* Fully responsive design
* Hamburger menu for smaller screens

---

## ✨ Bonus Features (Optional)

You may implement any of the following for extra credit:

* 🌙 Dark/Light mode toggle
* 🔄 Smooth scrolling
* 🎞 Animations and transitions
* 🌐 API integration
* 🔍 SEO-friendly structure
* ♿ Accessibility improvements
* 🚀 Deployment (Netlify / Vercel / GitHub Pages)

---

## 📱 Responsiveness Requirements

Your design must work seamlessly on:

* Mobile devices
* Tablets
* Desktop screens

---

## 📂 Submission Requirements

Please submit:

### 📁 Source Code

* GitHub repository **(preferred)** or ZIP file

### 🌐 Live Demo (Optional but Recommended)

* Hosted version of your project

### 📘 README File

Include:

* Project overview
* Technologies used
* Instructions to run the project
